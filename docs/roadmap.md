# Roadmap

## MVP (v0.1)

1. **Profiles**: save current Dock, create, edit, rename, duplicate, apply; menu bar switcher; global hotkeys; auto-saved Default profile.
2. **Visual editor**: apps, URLs, folders/stacks, spacers; drag and drop from Finder; diff preview; batched apply with one Dock restart.
3. **Backup & undo**: plist snapshot before every apply; layout history.

## v0.2

4. **Dock preferences** panel with live preview and reset, stored per profile.
5. **Profile switching apps**: quit old / launch new (see [profile-switching.md](profile-switching.md)).
6. **Export** profile as `dockutil` script; JSON import/export.

## v0.3

7. **Triggers**: Focus Filter, display change, Wi-Fi, schedule, frontmost app.
8. **Shortcuts** actions (App Intents).
9. **CLI** (`ohmydock`) + URL scheme.

## v0.4+

10. Missing-app detection + `brew install --cask`.
11. Usage-based auto-ordering and suggestions.
12. iCloud sync.
13. MDM / fleet script output; multi-user (`--allhomes`).
14. Invisible mode; regular-app mode toggle.
15. Research: lock Dock to one display.
16. **Profile gallery**: GitHub-registry community gallery + `ohmydock://import` link sharing (see [profile-gallery.md](profile-gallery.md)).
